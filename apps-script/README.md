# AI_UNDERCOVER_API

- 현재 백업 버전: 0.1.0
- `Code.gs`: AI_UNDERCOVER_API 웹 앱의 서버 로직을 담는 Apps Script 소스 파일
- `appsscript.json`: Apps Script 프로젝트의 시간대, 런타임 등 설정을 정의하는 매니페스트 파일
- 필요한 Script Properties 이름: `API_SECRET`, `SPREADSHEET_ID`
- `API_SECRET`과 `SPREADSHEET_ID`의 실제 값은 저장소에 커밋하지 않는다.
- Apps Script 배포 URL은 저장소에 커밋하지 않는다.
- 배포 방식: 웹 앱 / 실행 사용자 본인 / 접근 권한 모든 사용자
- 코드를 변경한 후에는 Apps Script에서 새 버전을 배포해야 한다.
