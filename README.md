# AI 언더커버

수업에서 모둠별로 참여하는 AI 언더커버 활동을 위한 반응형 웹앱 UI입니다. 현재 단계에서는 더미 데이터만 사용합니다.

## 개발 환경

- Vite
- React
- TypeScript
- React Router

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`로 확인할 수 있습니다.

## 화면

- `/` — 수강생 참여 코드 입력
- `/admin` — 강사 패드 운영 화면
- `/display` — 프로젝터 공유 화면
- `/team` — 모둠 대표 입력 화면
